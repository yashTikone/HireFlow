# HireFlow Client

## Local development

1. Run `npm install` in this folder.
2. Run `npm run dev`.
3. Start the API separately from `../server`.

The client API base URL is configured in `src/services/api.js`. Update it to your deployed API URL before production deployment.

Candidate resume upload is available in the Profile page. Uploads accept PDF files up to 5 MB. Recruiters can run resume matching from the applicants page for their own jobs.
